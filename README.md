# Urban Slum Detection & Infrastructure Planning

Satellite imagery-based ML classification of informal settlements to support city planners in Lagos, Abuja, Ibadan, Port Harcourt, Kano, and Accra. Identifies high-density informal areas for prioritized water, sanitation, and road infrastructure investment.

---

## Features

- Gradient Boosting classifier on 12 satellite-derived features
- Probability mapping with confidence tier (Low / Medium / High)
- Interactive detection map with Plotly Mapbox
- Custom grid-cell classification tool
- City-level informal settlement rate analysis

---

## Setup & Run

```bash
git clone https://github.com/Momahmoses/urban-slum-detection.git
cd urban-slum-detection
pip install -r requirements.txt
streamlit run streamlit_app.py
```
